Introduction

This repository contains my solutions for three JavaScript exercises. The exercises demonstrate DOM manipulation, event listeners, input validation and dynamic list generation.

Question 1: Change Message

This program changes the welcome message when the user clicks the Change Message button.

How to run: Open Q1/questionOne.html in a web browser and click Change Message.

Expected output: The message changes from "Welcome to my website!" to "Hello there!".

Screenshot: See the Question 1 screenshot in the Q1 folder.

Question 2: Smart Number Validator

This program checks whether the user's input is a valid number and compares it with 10.

How to run: Open Q2/questionTwo.html in a web browser, enter a number and click Check.

Expected output: The page displays whether the number is lower than, higher than or equal to 10. Invalid input displays an error message.

Screenshot: See the Question 2 screenshot in the Q2 folder.

Question 3: Dynamic Number Generator

This program creates an ordered list containing five numbered items when the user clicks Generate.

How to run: Open Q3/questionThree.html in a web browser and click Generate.

Expected output: The page displays five list items from 1 to 5.

Screenshot: See the Question 3 screenshot in the Q3 folder.
